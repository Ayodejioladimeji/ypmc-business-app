# To start the app

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
    npm run start
   ```

## Components
All rider components start with Rider e.g RiderSidebar, RiderBottom, etc.

All partner components start with Org e.g OrgActiveRiders, etc.

There's a general components folder that contains common or shared components.

## Learn more

Redux Toolkit Query was used to achieve data fetching and automatic caching.

All rider API calls are redux/actions/rider

All rider API calls are redux/actions/org
